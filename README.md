## 🎯 What is Al-Jin?

**Al-Jin** is the **ultimate free, open-source, self-hosted WhatsApp Multi-Device bot** built with **Node.js** and **Baileys v7**. Designed for power users who demand complete control, privacy, and an extensive feature set — all without monthly subscriptions or cloud dependencies.

> 🕶️ **Stealth by default** — No online status. No read receipts. No auto-reacts. You are invisible.

## ✨ Feature Deep-Dive

<details open>
<summary><b>🕶️ Stealth Mode (Default Enabled)</b></summary>

- ❌ No "online" status visible to others
- ❌ No blue ticks / read receipts
- ❌ No "typing..." indicators
- ❌ No auto-reactions on status updates
- ✅ You read everything — nobody knows

</details>

<details>
<summary><b>🛡️ Anti-Delete & Anti-Edit</b></summary>

- Messages deleted by sender? **Al-Jin shows you what was removed**
- Messages edited? **See the original version**
- Works for text, images, videos, documents, and voice notes
- Optional logging to a private chat

</details>

<details>
<summary><b>👁️ View-Once Reveal</b></summary>

- View-once photos and videos are **saved and re-viewable**
- Bypasses WhatsApp's single-view restriction
- Media is stored locally on your device

</details>

<details>
<summary><b>⬇️ Universal Downloader</b></summary>

| Platform | Type | Quality |
|----------|------|---------|
| YouTube | Video / Audio / Shorts | Up to 4K |
| Instagram | Reels / Posts / Stories | HD |
| TikTok | No-watermark video | HD |
| Facebook | Public videos | HD |
| X (Twitter) | Videos / GIFs | Original |
| MediaFire | Direct files | Original |
| Pinterest | Images / Videos | HD |
| Spotify | Audio (via ytdlp) | 320kbps |

</details>

<details>
<summary><b>🤖 AI & Productivity</b></summary>

- **Gemini AI Chat** — Free conversational AI in any chat
- **PowerPoint Maker** — Generate `.pptx` from text prompts
- **Subtitle Generator** — Auto-subtitle any video

</details>

<details>
<summary><b>👥 Group Management</b></summary>

</details>

<details>

- Photo → Sticker (with crop, rounded, circle)

## ⚙️ Configuration

Create a `.env` file in the root directory:

```env
# Required
OWNER_NUMBER=923001234567        # Your WhatsApp number (country code, no +)

# Optional — AI Features
GEMINI_API_KEY=your_key_here     # Get free key at aistudio.google.com

# Optional — Customization
BOT_NAME=Al-Jin
PREFIX=.
STEALTH_MODE=true
ANTI_DELETE=true
VIEW_ONCE_REVEAL=true
```

> 🔑 **Free Gemini API Key:** Visit [aistudio.google.com](https://aistudio.google.com) → Get API Key → Paste in `.env`

## 🐳 Deployment

### Local / VPS (PM2 — Recommended)

```bash
npm install
npm run pm2:start        # Start with auto-restart
npm run pm2:logs         # View logs
npm run pm2:restart      # Restart bot
```

### Docker

```bash
docker build -t al-jin .
docker run -d --name aljin --restart unless-stopped al-jin
```

### Termux (Android)

```bash
pkg update && pkg upgrade -y
pkg install -y nodejs git ffmpeg
git clone https://github.com/themalik-g/al-jin-whatsapp-bot.git
cd al-jin-whatsapp-bot
npm install
npm start
```

## ❓ FAQ

<details>
<summary><b>Is Al-Jin free?</b></summary>

✅ **100% free & open-source** under MIT License. No hidden costs, no premium tiers.

</details>

<details>
<summary><b>Is it safe to use?</b></summary>

Al-Jin is **self-hosted** — your data never leaves your device. The bot uses the official WhatsApp Multi-Device protocol via Baileys. However, automation always carries some risk. Use responsibly.

</details>

<details>
<summary><b>Does it work on WhatsApp Business?</b></summary>

Yes. Al-Jin works on both **WhatsApp Messenger** and **WhatsApp Business** via the Linked Devices feature.

</details>

<details>
<summary><b>Can I run multiple bots?</b></summary>

Yes. Clone the repo into separate folders and use different `OWNER_NUMBER` values in each `.env` file.

</details>

<details>
<summary><b>Node.js version requirement?</b></summary>

**Node.js ≥ 20** is required. Check with `node -v`. Upgrade at [nodejs.org](https://nodejs.org).

</details>
