# Support

**WhatsApp support:** message **@insaf.pk** on WhatsApp, or [open a chat directly](https://wa.me/923257853673?text=Hi%2C%20I%20need%20help%20with%20Al-Jin). Support is free; no premium plan is needed.

## Before you write

1. Read [Troubleshooting](./whatsapp-bot-troubleshooting.md) and the [FAQ](./faq.md). Most problems are solved there.
2. Send these so you get a fast answer:
   - a screenshot of the error or the terminal window
   - your device (Windows, Android/Termux, Linux, macOS, server)
   - the command you sent

## Other ways

- Bugs and ideas: [GitHub issues](https://github.com/themalik-g/al-jin-whatsapp-bot/issues)
- Security problems: use a private security advisory, not a public issue
