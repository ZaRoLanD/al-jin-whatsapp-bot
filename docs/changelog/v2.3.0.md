# v2.3.0 — new plugins

| Command | What it does | Who |
|---|---|---|
| `.spotify <song>` | Cover card + MP3. Spotify API → YouTube API → built-in `.play` | everyone |
| `.alexa <song>` | MP3 from YouTube music. YouTube API → Spotify API → built-in `.play` | everyone |
| `.remini` | Sharpen and enlarge a photo (reply, send with it, or give a link). Online AI → built-in ffmpeg enhancer | everyone |
| `.tg <t.me/addstickers/pack> [n]` | Telegram sticker pack → WhatsApp stickers (static and video, max 50) | everyone |
| `.reactall on\|off` | Auto-react in every chat. Scope, skip / only lists, custom emoji. **Off by default** | owner |
| `.anim` | 16 edit-in-place animations (`.moon`, `.snake`, `.hypno` …), `.anim stop` | owner |
| `.tdl` | Download from Telegram links or search your exported chats | owner |

## Setup (only where needed)
- `.tg` needs a free Telegram bot token: `.setvar TELEGRAM_BOT_TOKEN <token>` ([how](../settings-and-keys.md)).
- `.tdl` uses the open-source `tdl` program. It is found on PATH, or downloaded once into the data folder. Log in with `.tdl login`, then set `TDL_CHATS` for search.
- `.remini` has a shared online key built in. Set `PRINCE_API_KEY` to use your own. If the online service is down, the built-in enhancer runs without any key.

## Safety limits
- Files above 100 MB are never downloaded or sent.
- Animations: one per chat, at most 48 edits, at least 0.7 s between edits.
- Telegram jobs run one at a time and temporary files are deleted after sending.
