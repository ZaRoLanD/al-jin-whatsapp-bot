# v2.2.0

## Stealth
- Account appears offline by default (re-asserted after connect and every 25 s).
- Status auto-view and auto-react are off by default; older saved settings are switched off once.
- Silent status saving still works and sends no "seen".

## Performance
- `tesseract.js` (OCR) and `bwip-js` (QR and barcodes) now load only when `.ocr` / `.qr` / `.barcode` is used, which lowers memory at startup.

## Project
- All notes moved into `docs/`. README is short and links to the details.
- One-click starters for Windows (`.bat`), macOS (`.command`), Linux and Termux (`aljin.sh`).
- Personal data (phone number, saved state) removed from the release files.
