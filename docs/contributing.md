# Contributing

[← Back to the README](../README.md) · [All docs](./README.md)

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature`
3. Commit: `git commit -m "Add your feature"`
4. Push: `git push origin feature/your-feature`
5. Open a Pull Request

Test files live in `test/`. Report bugs or request features in [GitHub issues](https://github.com/themalik-g/al-jin-whatsapp-bot/issues). For security problems, use a private security advisory instead of a public issue.
